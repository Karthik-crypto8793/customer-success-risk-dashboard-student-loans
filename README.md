# Customer Success Risk Dashboard for Overseas Student Loans

## Overview
This project demonstrates how customer success and operations teams in overseas student loan servicing can track customer journey stages, turnaround times, risk signals, and retention indicators across multiple geographies.

## Business Problem
In student loan and banking support operations, customers may drop off due to delays, unclear documentation, low engagement, or repeated follow-ups. Without a structured dashboard, it is difficult for leaders to identify risk early and improve service quality.

## Objective
Build a simple business dashboard that helps:
- track applications across journey stages
- identify high-risk customers
- monitor turnaround times
- analyze complaint and escalation trends
- compare performance by country and channel

## Scope
The dashboard includes sample data for:
- Customer ID
- Country
- Loan Stage
- Application Status
- Days in Current Stage
- Follow-up Count
- Complaint Flag
- Escalation Flag
- Risk Level
- Customer Satisfaction Score
- Channel
- Agent Name

## Tools Used
- Microsoft Excel
- CSV dataset
- GitHub for portfolio showcase

## Sample Insights
- Customers with 3+ follow-ups and 7+ days in the same stage show higher dropout risk
- Complaint and escalation flags are concentrated in document verification and sanction stages
- Certain channels may produce faster turnaround times than others
- Country-level differences may reveal process gaps or customer communication issues

## Key Outcome
This project shows how customer success leaders can use simple data models and dashboards to improve service quality, reduce churn risk, and support operational decision-making.
